# Utility Automation

This repository aims to automate the process of starting utilities when a property reaches a designated stage in GoHighLevel. The goal is to streamline setup and reduce manual steps by tying GoHighLevel's pipeline events to external service providers.

## Planned Approach

- **GoHighLevel Webhooks**: Trigger an automation whenever a property is moved to the target stage.
- **Python Scripts**: Process incoming webhook data and manage logic for starting utilities.
- **Third-party APIs**: Connect with external providers to enable electricity, gas, water, or other utilities automatically.

Further updates will detail the integration steps and provide example scripts.
